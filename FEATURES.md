# ✨ Полный список фич — Terra Engine v0.1 BETA

Этот документ описывает всё, что уже реализовано в движке на текущей бета-версии.

---

## 🎯 Философия движка

Terra Engine создан не как «конструктор с нуля», а как **готовый репозиторий**.
Пользователь, который вообще не разбирается в моддинге, кодинге и создании подобных вещей, может:

- склонировать репозиторий
- открыть встроенные настройки
- получить полностью рабочий, красиво анимированный мод без единой строчки кода

---

## 🎬 Переходы (Transitions)

- **20+ готовых видов переходов** между экранами
- Каждый переход настраивается индивидуально
- Регулируемая длительность (**Duration**): от `0.5s` до `3s`
- Переходы применяются ко всем ключевым экранам игры

---

## 🖥 Поведение главного меню

В настройках можно выбрать, как будет вести себя главное меню при пульсации под BPM:

- **Zoom** — обычное покачивание/масштабирование экрана в такт BPM
- **Zoom + Glitch** — зум с эффектом глитча
- **Zoom + Camera Rotation** — зум с поворотом камеры

---

## 🌀 Эффекты экранов (25+)

Более 25 видов визуальных эффектов, применяемых отдельно к каждому из экранов:

- **FreePlay**
- **Credits**
- **Settings**
- **Story Mode**

Каждый экран получает собственный независимый набор эффектов, что позволяет создавать уникальную атмосферу для каждого раздела игры.

---

## 🛠 Developer Mode

Подробно описан в [DEVELOPER_MODE.md](DEVELOPER_MODE.md), но кратко:

- Включается через `Settings → Additional → Developer Mode`
- Активируется в главном меню клавишей `7`
- Даёт доступ к 4 внутриигровым редакторам:
  1. Chart
  2. Character Settings
  3. Stage Editor
  4. Menu Layout

---

## 🗂 Menu Layout — уникальная система

Отдельная система, позволяющая полностью настроить:

- внешний вид главного меню
- поведение при переходах
- анимационное поведение элементов интерфейса

Это одна из ключевых отличительных фич Terra Engine по сравнению с другими движками.

---

## 📌 Статус

Движок находится в статусе **BETA (v0.1)** — часть функций может дорабатываться и изменяться в следующих версиях. Следи за обновлениями в [CHANGELOG.md](../CHANGELOG.md) и в Discord-сообществе.
