# 🤝 Как помочь проекту

Спасибо за интерес к развитию **Terra Engine**!

## Как сообщить об ошибке

1. Проверь, не сообщали ли уже об этой ошибке в [Issues](../../issues)
2. Если нет — создай новый Issue с:
   - описанием проблемы
   - шагами для воспроизведения
   - версией движка (например, `v0.1 BETA`)
   - скриншотом/видео, если возможно

## Как предложить фичу

Открой Issue с пометкой `feature request` и опиши:

- что должно делать
- зачем это нужно
- как это может выглядеть/работать

## Pull Request'ы

1. Форкни репозиторий
2. Создай отдельную ветку под свою фичу/фикс: `git checkout -b feature/my-feature`
3. Держи изменения в **раздельных файлах** — не смешивай логику разных систем в одном файле, это правило проекта
4. Опиши изменения в `CHANGELOG.md`
5. Открой Pull Request с понятным описанием
