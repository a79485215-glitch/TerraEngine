# 🛠 Developer Mode

Terra Engine включает встроенный режим разработчика, который позволяет настраивать мод изнутри игры — без редактирования кода вручную.

## Как включить

1. Открой **Settings**
2. Перейди в раздел **Additional**
3. Поставь галочку **Developer Mode**
4. Вернись в главное меню
5. Нажми клавишу **`7`**

После этого откроется меню разработчика с четырьмя разделами.

---

## 1️⃣ Chart

Раздел отвечает за настройку музыкальной и игровой части чарта:

- эффекты самой музыки
- переходы персонажей (смена анимаций/поз)
- поведение и стиль летящих нот (стрелок)

---

## 2️⃣ Character Settings

Раздел для настройки персонажей:

- анимации персонажей
- размеры спрайтов
- скорость воспроизведения анимаций

---

## 3️⃣ Stage Editor

Классический редактор сцены:

- настройка слоёв (layers)
- расположение объектов на стейдже
- прочие параметры окружения

---

## 4️⃣ Menu Layout

Одна из ключевых фишек движка — гибкая настройка главного меню:

- внешний вид главного меню
- поведение элементов интерфейса
- переходы и анимации внутри меню

---

## ℹ️ Примечание

Developer Mode рассчитан как на новичков (можно всё настроить визуально, без кода), так и на опытных мод-мейкеров, которым нужен быстрый доступ к тонкой настройке без пересборки проекта.
